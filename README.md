# Dad Joke Showdown — one dad joke

[![rank](https://make.fun/badge/u-mfnakmal-dad-joke-showdown-1d2ce3e5/wessmari97/dad-joke-01/rank.svg)](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5/leaderboard)
![reward](https://make.fun/badge/u-mfnakmal-dad-joke-showdown-1d2ce3e5/wessmari97/dad-joke-01/reward.svg)

One dad joke, at most 200 characters, for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun. A judge model reads the jokes two at a time and picks the one that lands the bigger groan.

The joke: "My son asked me what a dad joke is. I said, 'Hi, What-A-Dad-Joke-Is. I'm Dad.'"

`main.ts` writes the joke to `${OUTPUT_DIR || '/output'}/entry.txt` with a 1–200 character guard.

Built for the make.fun bounty by [@mase-ayas](https://make.fun/r/jrnh2cfm?ref=jrnh2cfm). Entry for the Dad Joke Showdown — one joke, one groan.
